# Nacos Tray

Windows 系统托盘小工具，监控 Nacos 服务注册中心实例状态，支持在线/下线管理。

## 适用版本

- **Nacos v3.2.1**（v3.x 全系列兼容）

## 快速上手

1. 运行 `NacosTray_v2.exe`，通知区域出现托盘图标
2. 右键托盘图标 → **设置**，填写 Nacos 连接信息
3. 保存后自动开始轮询，服务状态变更时弹出气泡通知
4. 左键双击托盘图标还原主窗口

## 功能说明

### 1. 服务监控面板（主窗口）

以表格展示所有服务实例：

| 列 | 说明 |
|---|---|
| 服务名 | 注册的服务名称 |
| 实例 | IP 地址（有备注则显示为 `IP(备注名)`） |
| 端口 | 实例端口号 |
| 状态 | **[在线]** / **[离线]**，颜色区分 |
| 最近上线时间 | 该实例最近一次变为在线的时间 |

底部状态栏显示总服务数和在线数，左侧圆点颜色标识整体健康状态（绿=全部在线，橙=部分离线）。

### 2. 实例上下线管理

- **右键**服务列表中的任意行 → 弹出上下文菜单 → **上线** / **下线**
- **双击**服务列表中的任意行 → 快速切换上下线
- 右键托盘图标 → 服务名称上直接点击切换
- 每次操作前弹出确认框，防止误操作

操作结果通过气泡通知反馈。

### 3. 系统托盘

| 操作 | 行为 |
|---|---|
| **左键双击** | 还原主窗口 |
| **右键** | 弹出快捷菜单：服务列表、还原窗口、设置、刷新、退出 |
| **气泡通知** | 服务上线 / 下线 / 移除时自动弹出 |

托盘悬浮提示显示 Nacos 地址和当前在线/离线统计。

### 4. IP 备注管理

为 IP 地址添加可读别名，方便识别。

- 主窗口顶部 → **IP备注管理** 按钮
- 可**新增 / 编辑 / 删除**备注
- 自动检测本机 IP 并标记为"本机"
- 所有列表中显示为 `IP(备注名)`

### 5. 配置设置

主窗口顶部 → **设置** 按钮，或右键托盘 → **设置**。

| 配置项 | 说明 | 默认值 |
|---|---|---|
| IP | Nacos 服务器地址 | `your-nacos-server.com` |
| 端口 | Nacos 端口 | `8848` |
| 命名空间 | Nacos 命名空间 ID | `dev2v` |
| 用户名 | 登录用户名 | `dev` |
| 密码 | 登录密码 | `1234567` |
| 登录刷新间隔 | 重新登录间隔（秒） | `1800` |
| 状态轮询间隔 | 服务状态刷新间隔（秒） | `30` |
| 开机自动启动 | 登录时自动启动本工具 | 关闭 |

支持 **测试连接** 按钮验证配置是否正确。

### 6. 自动刷新与状态通知

- 按设定间隔自动轮询 Nacos API
- 智能检测状态变化，**仅首次变化时**触发通知（避免重复弹窗）
- Token 有效期 20 分钟，过期自动重新登录

## 配置文件

| 文件 | 路径 | 说明 |
|---|---|---|
| `config.json` | `exe 同级目录/.nacos-tray/config.json` | 连接配置、轮询间隔等 |
| `notes.json` | `exe 同级目录/.nacos-tray/notes.json` | IP 备注数据 |

手动修改配置文件后需重启工具生效。

## FAQ

**Q: 如何设置开机自启？**
A: 打开设置对话框，勾选「开机自动启动」并保存。注册表写入 `HKCU\...\Run`。

**Q: 托盘图标消失了怎么办？**
A: 重新运行 exe 即可。如果频繁消失，检查 Nacos 连接是否正常。
