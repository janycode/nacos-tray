# 设置集中到单一入口，视图与快捷键可配置

## Status

accepted

## Context

主窗口顶部此前并排放着视图切换、刷新、IP 备注管理、设置和关于五个入口；设置窗口用三个等大的横向页签承载连接、行为、外观；刷新固定为 F5；卡片视图的列数与字段全部写死；备注管理和关于是独立弹窗。卡片视图还缺少快速查看完整信息的途径。

## Decision

1. 顶部栏只保留标题与右上角齿轮；视图切换、刷新、备注管理、关于都从顶部移除。齿轮直接打开设置面板。
2. 设置面板改为左侧竖向侧边栏，固定六个页面：连接、行为、外观、快捷键、备注、关于。选中项字号更大、加粗并使用强调色，未选中项使用常规小字。
3. 外观页内分主题、视图、卡片、表格四段，整页可滚动。视图模式（表格/卡片）放在这里，保存后立即切换并持久化。
4. 卡片样式可配置：每行列数（自动 / 1 / 2 / 3）、密度（紧凑 / 标准 / 宽松，对应不同的卡片最小宽度）、服务名字号（小 / 标准 / 大 / 特大）、显示字段（端口、在线数、最近上线时间、备注名、免打扰标记）。固定列数在窗口放不下时自动降列；窄卡片自动隐藏最近上线时间。
5. 表格样式可配置：行高（紧凑 / 标准 / 宽松）与斑马纹开关；置顶列始终保留。
6. 快捷键可配置三项：刷新（默认 F5）、切换表格/卡片（默认 Ctrl+Tab）、打开设置（默认 Ctrl+,）。只在主窗口获得焦点时生效；允许清空表示禁用；动作之间不允许重复；冲突时阻止保存；提供恢复默认。
7. 备注管理内嵌为设置页，改动立即写入 `notes.json`；关于页内嵌版本信息与更新记录，不再有独立窗口。
8. 卡片视图增加悬浮详情：停留约 400ms 后弹出只读浮层，展示全局连接信息、服务汇总以及每个实例的完整字段，包括已启用/健康状态、权重、集群、临时/持久与元数据；最多列 12 个实例，超出显示剩余数量。浮层不抢焦点，移出卡片即消失。
9. 顶部标题只显示当前版本号，不再拼接作者。

## Considered Options

- 保留刷新与视图切换按钮，只把备注/关于收进设置：入口更少，但没有达到“只留一个齿轮”的目标。
- 设置继续用横向页签：实现最省事，但页签会增加到六个，且无法自然实现“选中的大、没选中的小”。
- 备注与关于继续用独立弹窗、设置里只放入口按钮：改动小，但不满足“聚合到设置”。
- 快捷键做全局热键：需要注册系统热键，冲突和权限问题多；主窗口内生效已覆盖日常使用。
- 悬浮信息用卡片就地展开：会改变卡片高度并推挤布局，浮层更稳定。

## Consequences

- `config.json` 新增 `card_columns`、`card_density`、`card_fields`、`table_row_height`、`table_striped`、`shortcuts`；缺失时按默认值补齐，旧配置可直接升级。
- 顶部不再有刷新按钮，刷新入口变为快捷键、行为页的“立即刷新”和托盘弹窗，需保证这三处都可用。
- 设置面板需要在主题切换重建时保留当前侧边栏页面与外观页滚动位置。
- 悬浮详情依赖 Nacos 实例响应中的权重、集群、临时实例与元数据字段；接口未返回时按缺省值显示。
- 卡片字段与列数变化在保存后通过重建主窗口立即生效。
